# Supply Chain

Monorepo do projeto Supply Chain: rastreio de pacotes com backend em Spring Boot e frontend em Angular.

- [`api/`](./api): API REST em Spring Boot (Java 17, PostgreSQL, RabbitMQ). Veja [api/README.MD](./api/README.MD).
- [`web/`](./web): Frontend em Angular (TypeScript, Tailwind, i18n PT-BR/EN-US). Veja [web/README.md](./web/README.md).

Os dois projetos foram unificados neste repositório em 2026-08-07 (antes viviam em `Supply-chain-API` e `Supply-chain-web` separados); o histórico de commits de ambos foi preservado.
